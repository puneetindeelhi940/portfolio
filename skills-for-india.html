§ 03 · METHODOLOGY // six principles for building skills that fit india

Built for India,
not translated for India.

Localisation is not a translation pass. Every skill here ships with six things a generic skill doesn’t: the right calendar, the right script, the right register, the right regulator, the right number system, and the right failure modes. The principles below are what made the difference.

01

Localise the inputs, not the outputs

The hardest part of an Indian skill is the input: PhonePe-merchant strings, CAS quirks, 26AS columns, BLO addresses. Get the input model right and the output writes itself.

02

Calendars are load-bearing

Fiscal year ends March 31, GST on the 20th, ITR on July 31, exam season in February. Skills are scheduled, not just functional. A “when” field beats a “summary” field every time.

03

Register before vocabulary

The most polite Tamil sentence is rarely the most direct. The kindest Hindi reads as honorific, not casual. Skills encode register first; vocabulary follows.

04

Regulators are the unspoken users

RBI, SEBI, FSSAI, ECI, ASI — every category in this directory has a regulator who decides what “right” means. Skills cite the source, not the press release.

05

Numbers, names, and addresses are not universal

Lakhs and crores are not optional. Mononyms break form validation. PIN codes encode geography. A skill that gets these three right is already 60% useful.

06

Failure modes are local too

Connectivity drops, IRP timeouts, vernacular OCR confusions, low-literacy fallbacks — these are not edge cases here, they are the path. Skills are designed to degrade gracefully, in Hindi.

§ 04 · USAGE // four ways to put these skills to work

How to use
Skills for India.

1

In Claude.ai

Open a new chat, click the skills picker, and pick a SK.NN by ID. Drop in your file or pasted text. The skill prompts you for the few inputs it needs.

2

In Claude Code

Run the install line in the card drawer, e.g. claude skills add sfi/<name>. Skills run inside your repo and can read project files, write outputs, and call your tools.

3

Via the API

Download the skill ZIP. It contains a system prompt, input schema, and example prompts. Wire it into your stack with tools=[…] on Anthropic’s messages endpoint.

4

Fork & remix

Every ZIP is a starter kit. Use Anthropic’s Skill Creator to adapt one for your state, your registrar, your sector — and submit it back to this directory.

// WHY THIS EXISTS

Global skills are great.
Local skills are better.

A skill that summarises a PDF is useful. A skill that summarises an RBI Master Direction on FX is load-bearing for the team that has to act on it Monday. This directory is built around that distinction — skills that know GST returns close in Hindi every 20th, that monsoon nowcasts mean different things in Mumbai and Mussoorie, and that the most polite version of a sentence in Tamil is not its most direct one.
