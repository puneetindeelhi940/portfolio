India.

A working directory of Claude skills built for Indian use-cases — GST returns, UPI receipts, Devanagari and South-Indian language work, RTI drafts, NCERT explainers, IRCTC PNRs, GeM tenders. The same idea as MSkill, narrowed to the problems we actually run into here. Each skill ships with a one-line install, a sample prompt, and a “why this matters here” note.

§ 03 · USAGE // four ways to put these skills to work

How to use
Skills for India.

1

In Claude.ai

Open a new chat, click the skills picker, and pick a SK.NN by ID. Drop in your file or pasted text. The skill prompts you for the few inputs it needs.

2

In Claude Code

Install from the marketplace: claude-code skills add sfi/name. Skills run inside your repo and can read project files, write outputs, and call your tools.

3

Via the API

Each skill ships a system prompt and a JSON schema. Wire it into your stack with tools=[…] on Anthropic’s messages endpoint. Indian context stays in the prompt.

4

Build your own

Use Anthropic’s Skill Creator and add the “India context pack’’ — calendars, currency, address formats, languages. PR a new skill back to this directory.

// WHY THIS EXISTS

Global skills are great.
Local skills are better.

A skill that summarises a PDF is useful. A skill that summarises an RBI Master Direction on FX is load-bearing for the team that has to act on it Monday. This directory is built around that distinction — skills that know GST returns close in Hindi every 20th, that monsoon nowcasts mean different things in Mumbai and Mussoorie, and that the most polite version of a sentence in Tamil is not its most direct one.
