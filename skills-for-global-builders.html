§ 01 · DIRECTORY // claude skills for builders shipping AI features in production

Skills for
Global Builders.

A working directory of Claude skills built for the people shipping AI features — engineers, PMs, designers, researchers, growth and docs. Each card opens with the system prompt, inputs, install line, and a downloadable skill package — a real ZIP you can drop into Claude.ai or Claude Code. The directory is opinionated about one thing: a skill earns its place by reducing a step from your day, not by impressing on a screenshot.

§ 03 · USAGE // four ways to put these skills to work

How to use
Skills for Global Builders.

1

In Claude.ai

Open a new chat, click the skills picker, and pick a GB.NN by ID. Drop in your file or pasted text. The skill prompts you for the few inputs it needs.

2

In Claude Code

Run the install line in the card drawer, e.g. claude skills add gb/<name>. Skills run inside your repo and can read project files, write outputs, and call your tools.

3

Via the API or MCP

Download the skill ZIP. It contains a system prompt, input schema, and example prompts. Wire it into your stack with tools=[…] or expose it via an MCP server.

4

Fork & remix

Every ZIP is a starter kit. Use Anthropic’s Skill Creator to adapt one for your team's voice guide, your runbook style, or your component library.

// THE BAR

A skill earns its place
by removing a step, not by adding a feature.

Every skill in here passes the same test: does it remove a step from a builder’s day, every time they use it? If the answer is “sometimes” or “impressively”, it doesn’t belong here. The directory is opinionated, narrow, and built to grow only along the edge where work is actually slow.
