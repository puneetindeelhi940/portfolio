Framework · FW-02 AI Trust

The AI Decision Confidence Scale

A shared language for how sure the model is — so the interface can stop pretending it always knows.

Models are confidently wrong all the time. The interface almost never says so — we render a wild guess and a near-certainty in exactly the same font.

Then we act surprised when people either trust the machine too much or stop trusting it at all. Calibrated trust is impossible if uncertainty is invisible. The scale gives a team one vocabulary for it, and one rule for what the UI does at each level.

01

The problem

Confidence is information the model already has and the interface throws away. A retrieval built on one weak source and one built on twelve strong ones look identical on screen.

Without a shared scale, every designer invents their own hedging — a ‘might’, a ‘possibly’, a grey tooltip — and every user learns to ignore all of it. Hedging that’s everywhere is hedging nobody reads.

02

The model

Four bands, lowest to highest: Guess, Suggest, Recommend, Assert. Each maps to a confidence range, a tone of voice, and — the part that matters — a required interface behaviour.

A Guess must offer an easy out. An Assert may act, but has to leave a trace. The band picks the verb, and the verb picks the UI.

Four bands. Each one dictates the verb, the tone, and what the interface is required to do.
03

Principles

  1. Say the meaning, not the number

    ‘One source’ lands with a person in a way ‘0.62’ never will.

  2. Match the verb to the confidence

    Don’t ‘recommend’ on a guess. The word is a promise.

  3. The louder the claim, the clearer the undo

    Assertion buys you action only if you also buy the user a way back.

  4. Never launder a guess into an assertion

    Dressing up uncertainty to look smart is how you lose a user for good.

04

How I use it

Pick the four words with engineering and content early — the vocabulary matters as much as the thresholds.

Wire each band to a component state, so a designer can’t accidentally render quiet confidence on top of a wild guess. Then hold the line in reviews: the band is not a suggestion.
