Framework · FW-04 Agent UX

The Agent Collaboration Model

Patterns for how humans and several agents split the work, hand off cleanly, and stay accountable to each other.

One assistant was simple. The moment you have three agents and a person, you have an org — and orgs need structure or they turn into a group chat where nobody owns anything.

I treat AI not as a feature to be designed but as a teammate to be onboarded. This is the small set of patterns I keep reaching for so the work has an owner at every step.

01

The problem

Multi-agent systems fail the way bad teams fail: unclear ownership, dropped hand-offs, and no one who can say why a decision was made.

The interesting design question was never ‘can the agents talk to each other’. It’s ‘who’s accountable when they do’.

02

The model

Four patterns, picked by the shape of the work. Relay — a chain, each agent hands to the next. Panel — several weigh in, one synthesises. Orchestrator — one agent plans and delegates to specialists.

And running through all of them, the Human checkpoint: the named place where a person can see the work and stop it. It’s not a fourth pattern — it’s the thing that makes the other three safe.

An orchestrator delegating to specialists, with a human checkpoint that can halt the outcome.
03

Principles

  1. Design the seam, not just the nodes

    Every hand-off is a place work goes to die. That’s where the design effort belongs.

  2. One synthesiser

    A panel that never converges is just noise with more steps and a bigger bill.

  3. Name the owner at each step

    Including the human one. ‘The system decided’ is not an owner.

  4. Make the reasoning legible

    If the person can’t follow how the agents got there, the checkpoint is decorative.

04

How I use it

Draw the work as a flow first, then ask which pattern actually fits: chain, panel, or orchestrator. Most teams reach for orchestration when a relay would do.

Put a human checkpoint wherever the Override Matrix says the stakes demand one. And if you can’t name who owns a step, the design isn’t finished — it just looks finished.
