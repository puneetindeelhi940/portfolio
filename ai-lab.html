§ AI LAB · a working lab, not a portfolio

The questions that wouldn’t leave me alone.

I don’t build these to prove I can use AI — everyone can now. I build them to chase the questions that won’t quit: how memory should feel, when an agent should ask instead of act, what honest uncertainty looks like on a screen. Each one links to the working thing. Not the tech — the thinking.
